Manifest audit

Decodes the binary AndroidManifest: permissions, exported components, debuggable/backup flags, SDK levels.

🔑

Secret scanning

Hunts DEX bytecode for hard-coded API keys, tokens, private keys and cleartext HTTP endpoints.

✍️

Signature check

Detects v1/v2/v3 signing schemes, weak certificate algorithms and debug-key signing.

🧭

Fix guide

Every finding comes with severity, evidence, and copy-pasteable remediation steps and code.
